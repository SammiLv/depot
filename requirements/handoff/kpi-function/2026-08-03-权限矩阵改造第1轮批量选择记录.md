# 权限矩阵改造第 1 轮批量选择记录

## 1. 本轮目标

为菜单权限、年度指标权限和 KPI 权限增加统一的权限矩阵批量选择能力，同时保留现有草稿、取消和保存语义。

本轮不实现“保存并同步至所有部门”，不修改数据库结构，不移除旧单格同步入口。

## 2. 已完成内容

### 2.1 通用纯函数

新增 `src/lib/permission-matrix.ts`：

- `getPermissionSelectionState`：计算选中、未选中和半选状态。
- `setPermissionCellsAllowed`：批量全选或清空目标单元格。
- `countPermissionCellChanges`：计算初始矩阵与草稿矩阵的变更数量，供下一轮确认弹窗复用。

批量修改统一产生以下草稿状态：

```text
allowed: 目标值
source: 当前 SYSTEM 或 DEPARTMENT 范围
explicit: true
inherited: false
```

### 2.2 三类矩阵控件

菜单权限、年度指标权限、KPI 权限均已增加：

1. 左上角全矩阵三态复选框。
2. 每个角色列的三态复选框。
3. 部分单元格开启时显示半选状态。
4. 当前并非全部开启时，点击执行全选。
5. 当前已经全部开启时，点击执行清空。

没有管理权限的用户只看到原状态，不显示批量控件。

### 2.3 菜单核心入口保护

管理员的以下菜单继续强制锁定：

- `/organization`
- `/dashboard`

它们不参与全矩阵或管理员列的全选状态计算，批量清空也不会修改这些单元格。

### 2.4 部门继承处理

部门范围批量操作后，目标单元格从系统继承状态转为部门显式草稿。点击“取消”仍使用原有重置逻辑恢复服务端传入的初始矩阵。

### 2.5 兼容入口

原单格“应用到全部部门”魔法棒入口继续保留。本轮没有改变现有保存 Server Action 和数据库持久化逻辑。

## 5. 页面验收路径

服务地址：`http://localhost:3004/organization?tab=permissions`

依次验证菜单权限、年度指标权限和 KPI 权限：

1. 点击左上角复选框，全矩阵全选。
2. 再次点击，全矩阵清空。
3. 点击单个角色列复选框，只改变该角色列。
4. 手动调整一个单元格，确认表头显示半选。
5. 点击“取消”，确认恢复保存前状态。
6. 菜单权限批量清空后，确认管理员的组织与权限、首页工作台仍为开启且不可编辑。
7. 部门范围批量操作后，确认目标单元格不再显示继承状态，取消后恢复继承状态。
