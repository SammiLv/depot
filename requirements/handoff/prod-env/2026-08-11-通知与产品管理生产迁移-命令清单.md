## Step 2：记录数据基线（不停服）

**目的**：迁移后对比行数，确认无数据丢失。

```bash
cd /c/appdeploy/depot

sqlite3 db/dev.db <<'SQL'
SELECT 'User' AS tbl, COUNT(*) AS cnt FROM User
UNION ALL SELECT 'Project', COUNT(*) FROM Project
UNION ALL SELECT 'Project_active', COUNT(*) FROM Project WHERE deletedAt IS NULL
UNION ALL SELECT 'Project_with_goal', COUNT(*) FROM Project WHERE productGoalId IS NOT NULL AND deletedAt IS NULL
UNION ALL SELECT 'ProductGoal', COUNT(*) FROM ProductGoal
UNION ALL SELECT 'QuarterlyWork', COUNT(*) FROM QuarterlyWork
UNION ALL SELECT 'PersonalKpi', COUNT(*) FROM PersonalKpi
UNION ALL SELECT 'AnnualGoalPlan', COUNT(*) FROM AnnualGoalPlan
UNION ALL SELECT 'OrgPermissionGrant', COUNT(*) FROM OrgPermissionGrant
UNION ALL SELECT 'OrgNode', COUNT(*) FROM OrgNode;
SQL
```

**请保存输出**（Cursor 可粘贴到对话记录），尤其 `Project_with_goal` 数值。

**预检：无效 productGoalId（必须为 0 行）**

```bash
sqlite3 db/dev.db "
SELECT p.id, p.title, p.productGoalId
FROM Project p
LEFT JOIN ProductGoal g ON g.id = p.productGoalId
WHERE p.productGoalId IS NOT NULL AND p.deletedAt IS NULL AND g.id IS NULL;
"
```

**通过标准**：**0 行**。若有行，先修复数据，**不要继续 Step 5**。

- [ ] 无效 productGoalId = 0 行

**必须确认**（在 `.env` 中；生产已有钉钉配置则沿用，与测试环境保持一致）：

## 常见问题

| 现象 | 处理 |
|------|------|
| `npm: command not found` | Git Bash 加 PATH：`export PATH="/c/Program Files/nodejs:$PATH"` |
| Step 2 预检有无效 productGoalId | 先在 DB 修正 `Project.productGoalId` 或置 NULL，再迁移 |
| migrate 第 5 条失败 | 用 Step R 恢复备份；检查 Project 表 FK |
| build 失败 | 服务已停；修复代码 push 后重新 Step 4～8，**不要**重复 migrate（已 applied 会跳过） |
| 产品管理页无编辑按钮 | 预期：权限矩阵未配置；去组织与权限勾选产品管理权限 |
| 用户报 Server Action not found | 强刷；部署后正常现象 |
